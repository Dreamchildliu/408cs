# 第1章 计算机系统概述

## 1.2 计算机系统层次结构😐

1. **冯诺依曼机的基本思想**
>冯诺依曼机的特点:
>- 采用"**存储程序**"的工作方式.
>- 计算机硬件由 运算器, 控制器, 存储器, 输入/输出设备 5大部件组成.
>- 指令和数据以同等地位存储在存储器中,但计算机应能区分他们(按**执行阶段**和**控制信号**进行区分).
>- 指令和数据均由二进制组成.
>以运算器为核心.

2. **计算机功能部件**
>- 输入设备
>- 输出设备
>- 存储器
>**cpu不能直接访问辅助存储器,必须把辅助存储器里的内容调入主存后,才能被cpu所访问.**
>- 运算器
>- 控制器

3. 指令集体系结构(ISA)
>软件与硬件之间的界面就是ISA, ISA定义了
